# 03 地图基础操作

> 对应页面：`src/views/stage1/Lesson03_MapOperations.vue`

## 学习目标

- 区分 `flyTo` / `easeTo` / `jumpTo` / `fitBounds` 的使用场景
- 掌握常用地图事件与监听时机
- 会用 `NavigationControl` 辅助演示

## 相机动画 API 对比

| 方法 | 动画 | 典型场景 |
|------|------|----------|
| `flyTo(options)` | 曲线飞行，可配 `speed`、`curve` | 城市切换、大屏展示 |
| `easeTo(options)` | 线性/缓动过渡，`duration` | 旋转、倾斜、平滑移图 |
| `jumpTo(options)` | **无动画**，瞬间到位 | 初始化同步、性能敏感 |
| `fitBounds(bounds, options)` | 缩放到包含范围 | 行政区、轨迹全览 |

### flyTo 示例

```ts
map.flyTo({
  center: [121.47, 31.23],
  zoom: 11,
  speed: 1.2,    // 默认 1.2，越大越快
  curve: 1.5     // 飞行弧度，默认 1.42
})
```

### fitBounds 示例

```ts
// bounds: 西南角、东北角 [lng, lat]
map.fitBounds(
  [[73.5, 18.2], [135.0, 53.5]],
  { padding: 40, duration: 1500, maxZoom: 10 }
)
```

`padding` 可为数字或 `{ top, bottom, left, right }`，避免要素贴边。

### 旋转与复位

```ts
map.easeTo({ bearing: current + 45, pitch: 45, duration: 1000 })
map.easeTo({ bearing: 0, pitch: 0, duration: 800 })  // 指北
```

也可用 `map.resetNorthPitch()`（版本支持时）快速复位北向。

## 事件体系（本课演示）

| 事件 | 触发时机 |
|------|----------|
| `load` | 样式与必要资源首次加载完成 |
| `click` | 单击；`e.lngLat` 为点击坐标 |
| `zoomend` | 缩放结束（含动画结束） |
| `moveend` | 平移/旋转/缩放等导致相机变化结束 |
| `move` | 相机变化过程中连续触发 |

**命名规律：** 很多交互有 `*start` / `*end` 成对出现，如 `dragstart`、`dragend`。

### 点击拿坐标

```ts
map.on('click', (e) => {
  console.log(e.lngLat.lng, e.lngLat.lat)
  // 若需像素坐标：e.point
})
```

## 控件

```ts
map.addControl(new maplibregl.NavigationControl(), 'bottom-right')
```

位置：`top-left` | `top-right` | `bottom-left` | `bottom-right`。

## 常见坑

1. **动画未完成又触发 flyTo**：会排队或打断，需防抖或 `map.stop()`（视版本 API）
2. **fitBounds 跨日期线**：复杂范围需特殊处理或使用 `LngLatBounds` 工具类
3. **在 `load` 前 addLayer**：自定义数据层应等 `load` 或 `style.load`

## 面试要点

- **Camera** 状态：`center`、`zoom`、`bearing`、`pitch` 可单独 `easeTo` 只改一项
- **用户交互**与 **API 改相机**都会触发 `move`/`moveend`，业务逻辑注意区分来源（可用标志位）

## 练习

- 为每个城市按钮加上 `essential: true`（若 API 支持）减少动画被用户打断的问题
- 监听 `dblclick` 放大一级
