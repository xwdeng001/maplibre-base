# 08 矢量瓦片与栅格瓦片

> 对应页面：`src/views/stage2/Lesson08_Tiles.vue`

## 学习目标

- 理解 XYZ / WMTS 瓦片坐标系
- 对比 **raster** 与 **vector** 底图的优劣
- 会配置 `tileSize`、attribution、多源切换

## 瓦片金字塔

-  zoom `z` 每 +1，瓦片数量约 ×4
-  单瓦片常见 **256×256** 或 **512×512**（HiDPI / 部分矢量服务）

```
/z/x/y  →  第 z 级、第 x 列、第 y 行
```

## 栅格瓦片（Raster）

**特点：** 服务端或 CDN 已渲染成图片，客户端只贴图。

```ts
{
  type: 'raster',
  tiles: ['https://a.example/{z}/{x}/{y}.png'],
  tileSize: 256,
  attribution: '...'
}
```

| 优点 | 缺点 |
|------|------|
| 实现简单、样式固定 | 放大模糊、难以按属性改色 |
| 缓存友好 | 多语言注记需多套瓦片 |

**典型：** 天地图 WMTS、OSM 标准瓦片。

## 矢量瓦片（Vector）

**特点：** 传 PBF/MVT，客户端按 **Style + Layer** 绘制。

```ts
{
  type: 'vector',
  url: 'mapbox://...'  // 或 tiles: [...]
}
```

Layer 需指定：

```ts
{
  id: 'roads',
  type: 'line',
  source: 'my-vector',
  'source-layer': 'transportation'  // 瓦片内图层名
}
```

| 优点 | 缺点 |
|------|------|
| 缩放清晰、样式可改 | 首屏解析耗 CPU/GPU |
| 可交互 query 要素 | 依赖 glyphs/sprite |

**典型：** MapLibre demotiles、Mapbox/OSM 矢量方案。

## 本课对比维度

| 维度 | Raster | Vector |
|------|--------|--------|
| 渲染位置 |  mostly 服务端 | 客户端 WebGL |
| 样式 | 换 URL/服务 | 改 style.json |
| 包体/依赖 | 小 | style+字体+图标 |
| 适合 | 影像、历史固定图 | 交互底图、专题 |

## 切换底图时的状态

`setStyle` 后 zoom/center 一般保留，但 **自定义图层丢失**；可记录 `map.getZoom()` 等再切换。

## 性能提示

- 多子域名 `tiles[]` 突破浏览器单域连接数限制
- `maxzoom` / `minzoom` 在 source 与 layer 上均可限制请求
- 影像底图 zoom 过大无意义，可 `maxzoom: 18`

## 面试要点

- **Web Mercator** 瓦片原点在西北，y 向下增
- 国内常遇 **坐标偏移**：GPS WGS84 vs 火星 GCJ02，底图与 GPS 需统一处理
- 天地图 **tk** 密钥需合规使用、域名白名单
