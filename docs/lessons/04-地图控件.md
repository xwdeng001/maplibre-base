# 04 地图控件

> 对应页面：`src/views/stage1/Lesson04_MapControls.vue`

## 学习目标

- 使用内置 `IControl` 控件
- 理解 `addControl` / `removeControl` 与摆放位置
- 实现自定义控件（实现 `onAdd` / `onRemove`）

## 内置控件一览

| 类 | 作用 |
|----|------|
| `NavigationControl` | 缩放 +/-、指南针（重置 bearing/pitch） |
| `ScaleControl` | 比例尺，`unit: 'metric' \| 'imperial'` |
| `FullscreenControl` | 全屏地图容器 |
| `GeolocateControl` | 浏览器定位，`trackUserLocation` 持续跟踪 |
| `AttributionControl` | 版权信息，可 `compact`、`customAttribution` |

```ts
map.addControl(new maplibregl.NavigationControl({
  showCompass: true,
  showZoom: true
}), 'top-right')
```

## 自定义控件：IControl 接口

```ts
class MyControl implements maplibregl.IControl {
  _map?: maplibregl.Map
  _container?: HTMLElement

  onAdd(map: maplibregl.Map) {
    this._map = map
    this._container = document.createElement('div')
    this._container.className = 'maplibregl-ctrl maplibregl-ctrl-group'
    map.on('move', this._update)
    this._update()
    return this._container  // 必须返回根节点
  }

  onRemove() {
    this._map?.off('move', this._update)
    this._container?.remove()
    this._map = undefined
  }

  _update = () => { /* 读 getCenter / getZoom 更新 DOM */ }
}
```

要点：

- 根元素建议带 `maplibregl-ctrl` 样式类，与官方控件视觉一致
- **`onRemove` 里必须解绑事件**，否则 `map.remove()` 后仍泄漏
- 控件 DOM 在 map 容器内，**不受 Vue scoped CSS 影响**（除非用 `:deep()`）

## 动态添加/移除

保存控件实例引用，`removeControl(instance)` 时传**同一对象**。

本课在 `load` 后再添加默认开启的控件，避免容器未就绪。

## Attribution 注意

构造 Map 时可 `attributionControl: false` 关闭默认，再手动：

```ts
new maplibregl.AttributionControl({
  compact: true,
  customAttribution: '© 你的项目'
})
```

天地图等底图还需在 **source.attribution** 或样式中保留法定声明。

## 面试要点

- 控件是 **DOM 叠加在 canvas 上**，不是 layer
- 自定义 UI（图例、时间轴）也可不用 IControl，用绝对定位叠在 map 容器上；IControl 好处是自动角落布局与 `remove` 生命周期
