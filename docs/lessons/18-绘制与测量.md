# 18 绘制与测量

> 对应页面：`src/views/stage4/Lesson18_Draw.vue`

## 学习目标

- 用地图 `click` 事件收集坐标，绘制点/线/面
- 用 GeoJSON source + layer **实时预览** 绘制结果
- 实现 **距离**（Haversine）与 **面积**（球面近似）计算

## 交互模式设计

```ts
const drawMode = ref<'none' | 'point' | 'line' | 'polygon'>('none')
const drawPoints = ref<[number, number][]>([])

map.on('click', (e) => {
  if (drawMode.value === 'none') return
  drawPoints.value.push([e.lngLat.lng, e.lngLat.lat])
  updateDrawSource()
})
```

绘制中应 `doubleClickZoom.disable()` 或双击结束线/面，避免冲突。

## 更新预览图层

```ts
function updateDrawSource() {
  const geojson = buildFeatureFromPoints(drawPoints.value, drawMode.value)
  ;(map.getSource('draw') as maplibregl.GeoJSONSource).setData(geojson)
}
```

线未闭合时仍用 `LineString`；面至少 3 点后 `Polygon`，首尾闭合。

## 距离：Haversine

两点大圆距离（米），本课公式适用于 **WGS84 经纬度** 短中距离：

```ts
function haversine(p1: [number, number], p2: [number, number]): number {
  const R = 6371000
  const toRad = (d: number) => (d * Math.PI) / 180
  const dLat = toRad(p2[1] - p1[1])
  const dLng = toRad(p2[0] - p1[0])
  const a =
    Math.sin(dLat / 2) ** 2 +
    Math.cos(toRad(p1[1])) * Math.cos(toRad(p2[1])) * Math.sin(dLng / 2) ** 2
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a))
}
```

折线总长：逐段累加 `haversine`。

## 面积

本课用 **简化球面多边形面积** 公式，适合教学演示。生产环境推荐：

- **Turf.js**：`area(polygon)`、`length(line)`
- 或投影到合适 CRS 再算

## 与专业绘制库对比

| 方案 | 说明 |
|------|------|
| 自研 click + GeoJSON | 轻量、可控，本课 |
| [@mapbox/mapbox-gl-draw](https://github.com/mapbox/mapbox-gl-draw) | 功能全，与 MapLibre 兼容需测试 |
| terra-draw 等 | 新一代绘制库 |

## 常见坑

1. 经纬度顺序 `[lng, lat]`
2. Polygon 外环必须闭合
3. 测量结果是 **椭球近似**，精密工程需专业 GIS
