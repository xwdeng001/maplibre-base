# 17 要素交互

> 对应页面：`src/views/stage4/Lesson17_Interaction.vue`

## 学习目标

- 使用 `queryRenderedFeatures` 拾取屏幕上的要素
- 用 **`feature-state`** 实现悬停高亮（无需改 GeoJSON）
- 区分 `mousemove` / `click` 与光标样式

## queryRenderedFeatures

```ts
const features = map.queryRenderedFeatures(e.point, {
  layers: ['areas-fill']  // 限定图层，性能更好
})
const feature = features[0]
```

- `e.point`：相对地图容器的像素坐标
- 也可用 `queryRenderedFeatures([[x1,y1],[x2,y2]])` 框选

返回的 `feature` 含 `properties`、`layer`、`source`、`id`（若数据有 id）。

## Feature 必须有 id（feature-state 前提）

GeoJSON 里显式设 `id`：

```ts
{ type: 'Feature', id: 1, geometry: ..., properties: { name: '西城区' } }
```

或在 source 上 `promoteId: 'yourProp'`。

## setFeatureState / removeFeatureState

```ts
map.setFeatureState(
  { source: 'areas', id: featureId },
  { hover: true }
)

map.removeFeatureState({ source: 'areas', id: featureId }, 'hover')
// 或 removeFeatureState({ source: 'areas' }) 清空
```

## 在 paint 里读 feature-state

```ts
'fill-color': [
  'case',
  ['boolean', ['feature-state', 'hover'], false],
  '#faad14',
  '#1890ff'
]
```

**注意：** `feature-state` 不能用于 layout 属性（部分版本有限制），主要用于 paint。

## 悬停流程（本课）

1. `mouseenter` / `mousemove` on layer → query 或 `e.features`
2. 清除上一个 `hoveredId` 的 state
3. 对新 id `setFeatureState({ hover: true })`
4. `mouseleave` → 清除 state，`map.getCanvas().style.cursor = ''`

```ts
map.on('mousemove', 'areas-fill', (e) => {
  map.getCanvas().style.cursor = 'pointer'
  // ...
})
```

## 点击 vs 悬停

- 悬停：轻量 state 更新
- 点击：可打开 Popup、写面板 `clickedInfo`

## 常见坑

1. 无 `id` 时 `setFeatureState` 无效
2. 未指定 `layers` 时可能点到底图矢量层，结果为空或不对
3. 面图层边缘 hover 抖动 → 适当 `fill-opacity` 或 tolerance

## 面试要点

- **feature-state** 适合高亮、选中，避免 `setData` 整表更新
- 矢量瓦片 id 来自 feature id 或 promoteId
