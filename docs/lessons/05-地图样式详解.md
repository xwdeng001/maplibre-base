# 05 地图样式详解（Style Specification）

> 对应页面：`src/views/stage2/Lesson05_MapStyles.vue`

## 学习目标

- 读懂 MapLibre **Style Spec v8** 顶层结构
- 区分 **本地 Style 对象** 与 **远程 style.json URL**
- 理解 `setStyle`、`getStyle`、`style.load` 事件

## Style 是什么

Style 是一份 JSON，描述：

1. **数据从哪来**（`sources`）
2. **怎么画**（`layers` 顺序 + type + paint/layout）
3. **字体与图标**（`glyphs`、`sprite`）

渲染顺序：**layers 数组中越靠后的图层越在上层**。

## 必需与常用字段

| 字段 | 必需 | 说明 |
|------|------|------|
| `version` | ✅ | 固定 `8` |
| `sources` | ✅ | 数据源字典 |
| `layers` | ✅ | 图层数组 |
| `glyphs` | 符号层需要 | `{fontstack}/{range}.pbf` URL 模板 |
| `sprite` | 图标需要 | 雪碧图 JSON+PNG 前缀 |
| `name` | | 标识用 |
| `center` / `zoom` / `bearing` / `pitch` | | 打开 style 时的默认视角 |

## 两种加载方式

```ts
// 1. 内联对象（天地图 raster 等）
map = new maplibregl.Map({ style: tiandituVecStyle, ... })

// 2. URL
map.setStyle('https://demotiles.maplibre.org/style.json')
```

URL 方式便于 CDN 缓存；内联方式便于拼接 key、多子域名 tiles 数组。

## 切换样式

```ts
map.setStyle(styleOrUrl)
```

**重要副作用：**

- 清除当前样式下所有 **运行时** 添加的 source/layer
- 触发新的样式加载，应监听 `style.load` 或 `load` 后重新 `addSource`/`addLayer`

```ts
map.on('style.load', () => {
  // 重新挂载业务图层
})
```

## 读取当前样式

```ts
const style = map.getStyle()
// sources、layers 等为解析后的对象
```

## 天地图样式结构（本项目）

`mapStyles.ts` 典型模式：

- 两个 `raster` source：底图 + 注记（cva/cia/cta）
- 两个 `raster` layer 叠加
- `tiles: string[]` 多子域名提升并行下载

## 工具链

- **Maputnik**：可视化编辑 style.json
- **MapLibre Style Spec 文档**：查 layer paint/layout 合法属性

## 面试要点

- Style 与 **数据** 分离：同一 GeoJSON source 可配多种 layer 表现
- **glyphs/sprite** 缺失时 symbol 层文字/图标不显示
- 矢量底图 style 体积大，常按 zoom 做 layer minzoom/maxzoom 优化
