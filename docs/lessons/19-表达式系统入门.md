# 19 表达式系统入门

> 对应页面：`src/views/stage5/Lesson19_Expressions.vue`

## 学习目标

- 理解 MapLibre **Expression** 语法（JSON 数组）
- 掌握 `get`、`match`、`case`、`interpolate`、`step`
- 把表达式用于 **paint** / **layout** 属性

## 表达式是什么

属性值可以是常量或表达式：

```ts
'circle-color': '#1890ff'                    // 常量
'circle-color': ['get', 'type']              // 表达式（一般不直接当颜色）
'circle-color': ['match', ['get', 'type'], ...]
```

第一个元素是 **运算符名**，后续是参数。

## 读取属性：get

```ts
['get', 'name']           // properties.name
['get', 'nested', 'x']    // 嵌套（若存在）
```

## 分支：match

等于某值 → 结果，可链式多个，最后是 default：

```ts
['match', ['get', 'type'],
  '景点', '#1890ff',
  '公园', '#52c41a',
  '#999'
]
```

## 分支：case

条件为真 → 结果（类似 if-else if）：

```ts
['case',
  ['==', ['get', 'level'], '高'], '#f5222d',
  ['==', ['get', 'level'], '中'], '#faad14',
  '#52c41a'
]
```

比较运算符：`==`, `!=`, `>`, `>=`, `<`, `<=`, `in` 等。

## 连续插值：interpolate

```ts
['interpolate', ['linear'], ['get', 'value'],
  0, '#52c41a',
  50, '#faad14',
  100, '#f5222d'
]
```

- 插值类型：`linear`、`exponential`、`cubic-bezier`
- 输入也可以是 `['zoom']` 做 **按缩放级别** 变化

## 阶梯：step

```ts
['step', ['get', 'value'],
  '#52c41a',    // 默认 < 第一个断点
  30, '#faad14',
  70, '#f5222d'
]
```

value < 30 → 绿；30~70 → 黄；≥70 → 红。

## 逻辑组合

```ts
['all', condition1, condition2]
['any', condition1, condition2]
['!', condition]
```

Filter 与 paint 表达式共用同一套语言。

## 类型注意

- 比较前确保类型一致，必要时 `['to-number', ['get', 'x']]`
- 颜色须是合法 CSS 颜色字符串

## 面试要点

- **数据驱动样式**：改数据不改代码
- `feature-state` 用 `['feature-state', 'key']` 读取（见第 17 课）
