# 22 运行时样式修改

> 对应页面：`src/views/stage5/Lesson22_RuntimeStyle.vue`

## 学习目标

- 掌握 **不改 style.json** 的前提下动态改图
- 熟练使用 `setPaintProperty` / `setLayoutProperty` / `setFilter`
- 管理图层顺序 `moveLayer` 与增删图层

## 运行时 API 一览

| API | 作用 |
|-----|------|
| `setPaintProperty(layer, name, value)` | 颜色、透明度、线宽等 |
| `setLayoutProperty(layer, name, value)` | visibility、text-size、icon-image 等 |
| `setFilter(layer, filter)` | 要素过滤 |
| `getPaintProperty` / `getLayoutProperty` | 读当前值 |
| `moveLayer(id, beforeId?)` | 调整叠放顺序 |
| `addLayer` / `removeLayer` | 增删图层 |
| `addSource` / `removeSource` | 增删数据 |

## Paint 示例

```ts
map.setPaintProperty('rt-fill', 'fill-color', '#f5222d')
map.setPaintProperty('rt-fill', 'fill-opacity', 0.4)
map.setPaintProperty('rt-outline', 'line-width', 3)
map.setPaintProperty('rt-circle', 'circle-radius', 10)
```

## Layout 示例

```ts
map.setLayoutProperty('rt-fill', 'visibility', 'none')  // 隐藏
map.setLayoutProperty('rt-label', 'text-size', 14)
```

visibility 比 removeLayer 更适合 **可恢复** 的显隐切换。

## moveLayer

```ts
map.moveLayer('rt-label')              // 移到最顶
map.moveLayer('rt-fill', 'rt-outline') // 放到 rt-outline 之前
```

图层顺序影响 **遮挡** 与 **点击 query** 优先级（上层先命中）。

## 与 setStyle 的区别

| | setPaintProperty 等 | setStyle |
|--|---------------------|----------|
| 范围 | 单个属性/图层 | 整张样式 |
| 自定义图层 | 保留 | 通常清空 |
| 场景 | UI 调色、开关 | 换底图 |

业务数据图层应在 `load` / `style.load` 后添加；换底图后要 **重新挂载** 或抽成 `function mountBusinessLayers()`。

## GeoJSON 数据更新

```ts
;(map.getSource('areas') as maplibregl.GeoJSONSource).setData(newData)
```

样式属性不必重设，除非字段变化导致表达式需调整。

## 本课 UI 模式

`reactive` 存面板状态 + 改地图时 **双向同步**（改色按钮 → setPaintProperty → 更新 reactive）。

操作日志便于调试 **调用顺序**（先 addSource 再 addLayer）。

## 常见坑

1. layer id 不存在会抛错 → 先 `getLayer`
2. `setPaintProperty` 第三参可以是表达式数组
3. removeLayer 后 paint 状态丢失，再 add 需重新设

## 面试要点

- 生产环境把「图层 id、默认样式」集中 **常量配置**
- 大量属性变更可批处理 + `requestAnimationFrame` 防抖
