# 20 数据驱动样式

> 对应页面：`src/views/stage5/Lesson20_DataDriven.vue`

## 学习目标

- 用 **interpolate / step** 做 choropleth（分级设色）与散点大小
- 同一套 `properties` 驱动 **颜色 + 半径**
- 理解「驱动字段」与图例设计

## 数据驱动全景

```
GeoJSON properties.value / population
        ↓
  interpolate 或 step 表达式
        ↓
fill-color / circle-radius / line-width ...
```

改 `setPaintProperty` 即可切换方案，无需重载数据。

## 面：分级设色（区域）

```ts
'fill-color': [
  'interpolate', ['linear'], ['get', 'population'],
  100, '#e0f3db',
  200, '#a8ddb5',
  300, '#43a2ca',
  420, '#0868ac'
]
```

或 step 离散分级：

```ts
'fill-color': [
  'step', ['get', 'value'],
  '#ffffcc',
  25, '#c7e9b4',
  50, '#7fcdbb',
  75, '#2c7fb8'
]
```

## 点：大小 + 颜色双驱动

```ts
'circle-radius': [
  'interpolate', ['linear'], ['get', 'value'],
  0, 4, 100, 16
],
'circle-color': [
  'interpolate', ['linear'], ['get', 'value'],
  0, '#52c41a', 100, '#f5222d'
]
```

本课 `driveTarget` 在 UI 上切换只改颜色、只改半径或两者。

## interpolate vs step 选型

| | interpolate | step |
|--|-------------|------|
| 视觉 | 连续渐变 | 清晰分档 |
| 适用 | 温度、比例 | 等级、风险档 |
| 图例 | 色带 | 阶梯块 |

## 图例与 UX

- 图例区间应与 **数据 min/max** 或分位数一致
-  outliers 会拉偏线性插值 → 考虑 `sqrt` 插值或分位数断点

## 与 Filter 配合

先 `filter` 缩小要素集，再对可见集设色（第 21 课）。

## 常见坑

1. `population` 是字符串 → `to-number`
2. 缺失属性 → 用 `coalesce`：`['coalesce', ['get', 'value'], 0]`
3. 面与点同时驱动时注意 **图层 id** 分开 `setPaintProperty`

## 面试要点

- **Choropleth** 要注意统计单位（面密度 vs 总值）— 误导性地图
- MapLibre 表达式在 GPU 执行，复杂表达式仍比改 GeoJSON 快
