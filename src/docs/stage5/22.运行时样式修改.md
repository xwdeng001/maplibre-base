# 22. 运行时样式修改

## 概述

MapLibre 提供了丰富的 API 在运行时修改地图样式。本节学习：

- setPaintProperty / setLayoutProperty
- setFilter / moveLayer
- addLayer / removeLayer
- 图层顺序管理

---

## Paint 属性修改

```ts
map.setPaintProperty('my-layer', 'fill-color', '#ff0000')
map.setPaintProperty('my-layer', 'fill-opacity', 0.5)
```

## Layout 属性修改

```ts
map.setLayoutProperty('my-layer', 'visibility', 'none')
map.setLayoutProperty('labels', 'text-size', 16)
```

## Filter 修改

```ts
map.setFilter('my-layer', ['>', ['get', 'value'], 50])
map.setFilter('my-layer', null) // 移除过滤
```

## 图层管理

```ts
// 添加图层
map.addLayer({ id: 'new-layer', type: 'circle', source: 'my-source', paint: { ... } })

// 移除图层
map.removeLayer('old-layer')

// 图层排序
map.moveLayer('layer-a', 'layer-b') // 将 a 移到 b 之前
```

---

## 本课小结

- `setPaintProperty` / `setLayoutProperty` 修改样式属性
- `setFilter` 动态过滤要素
- `addLayer` / `removeLayer` / `moveLayer` 管理图层
- 所有修改立即生效
