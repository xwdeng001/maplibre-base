# 20. 数据驱动样式

## 概述

数据驱动样式通过表达式将要素属性映射为视觉属性。本节学习：

- interpolate 连续插值
- step 阶梯分段
- 分级设色地图实战

---

## interpolate — 连续插值

在输入值之间进行平滑插值：

```json
["interpolate", ["linear"], ["get", "population"],
  0, "#f7fbff",
  500000, "#6baed6",
  1000000, "#08519c"
]
```

### 插值方式

| 方式 | 说明 |
|------|------|
| `["linear"]` | 线性插值 |
| `["exponential", base]` | 指数插值 |
| `["cubic-bezier", x1, y1, x2, y2]` | 贝塞尔曲线 |

---

## step — 阶梯分段

在阈值处直接跳变：

```json
["step", ["get", "value"],
  "#52c41a",        // value < 30
  30, "#faad14",    // 30 ≤ value < 70
  70, "#f5222d"     // value ≥ 70
]
```

---

## interpolate vs step

| 特性 | interpolate | step |
|------|-------------|------|
| 过渡方式 | 平滑渐变 | 阶梯跳变 |
| 适用场景 | 连续数值 | 分类/等级 |
| 视觉效果 | 色带渐变 | 色块分明 |

---

## 本课小结

- `interpolate` 适合连续数值的渐变映射
- `step` 适合分类或等级的分段映射
- 两者可用于 color / radius / width / opacity 等属性
