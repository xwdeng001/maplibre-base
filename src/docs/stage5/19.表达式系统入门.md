# 19. 表达式系统入门

## 概述

MapLibre 表达式是一种类似 JSON 的函数式语言，用于在样式中动态计算属性值。本节学习：

- 表达式语法基础
- 数据表达式 vs 相机表达式
- 常用表达式：get / has / == / case / match

---

## 表达式语法

表达式是一个 JSON 数组，第一个元素是操作符，后面是参数：

```json
["操作符", 参数1, 参数2, ...]
```

示例：
```json
["get", "name"]              // 获取属性 name
["==", ["get", "type"], "A"] // 判断 type 是否为 "A"
["+", 1, 2]                  // 计算 1 + 2
```

---

## 数据表达式 vs 相机表达式

| 类型 | 输入 | 用途 |
|------|------|------|
| 数据表达式 | 要素属性 | 根据数据动态设色/大小 |
| 相机表达式 | zoom 等 | 根据缩放级别变化样式 |
| 复合表达式 | 两者 | 同时依赖数据和缩放 |

---

## 常用表达式

### get — 获取属性值

```json
["get", "propertyName"]
```

### has — 判断属性是否存在

```json
["has", "propertyName"]
```

### 比较操作符

```json
["==", ["get", "type"], "A"]
["!=", ["get", "status"], "closed"]
[">", ["get", "value"], 100]
["<=", ["get", "score"], 60]
```

### case — 条件分支

```json
["case",
  ["==", ["get", "level"], "高"], "#f5222d",
  ["==", ["get", "level"], "中"], "#faad14",
  "#52c41a"
]
```

### match — 多值匹配

```json
["match", ["get", "type"],
  "景点", "#1890ff",
  "公园", "#52c41a",
  "商业", "#fa8c16",
  "#999"
]
```

### interpolate — 连续插值

```json
["interpolate", ["linear"], ["get", "value"],
  0, "#52c41a",
  50, "#faad14",
  100, "#f5222d"
]
```

### step — 阶梯分段

```json
["step", ["get", "value"],
  "#52c41a",
  50, "#faad14",
  80, "#f5222d"
]
```

---

## 本课小结

- 表达式是 MapLibre 动态样式的核心
- `get` / `has` 访问要素属性
- `case` / `match` 实现条件分支
- `interpolate` / `step` 实现数值映射
