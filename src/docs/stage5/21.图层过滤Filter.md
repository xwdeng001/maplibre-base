# 21. 图层过滤（Filter）

## 概述

Filter 表达式用于筛选要素，只渲染满足条件的数据。本节学习：

- filter 表达式语法
- 按属性筛选
- 组合条件：all / any / none

---

## 基本语法

```ts
map.addLayer({
  id: 'my-layer',
  type: 'circle',
  source: 'my-source',
  filter: ['==', ['get', 'type'], '景点']
})
```

---

## 比较操作符

```json
["==", ["get", "type"], "景点"]   // 等于
["!=", ["get", "status"], "关闭"]  // 不等于
[">", ["get", "value"], 50]       // 大于
[">=", ["get", "score"], 80]      // 大于等于
["<", ["get", "year"], 2020]      // 小于
```

---

## 组合条件

### all — 所有条件都满足

```json
["all",
  ["==", ["get", "type"], "景点"],
  [">", ["get", "value"], 50]
]
```

### any — 任一条件满足

```json
["any",
  ["==", ["get", "type"], "景点"],
  ["==", ["get", "type"], "公园"]
]
```

### none — 所有条件都不满足

```json
["!", ["any",
  ["==", ["get", "status"], "关闭"],
  ["<", ["get", "score"], 0]
]]
```

---

## 运行时动态修改 filter

```ts
map.setFilter('my-layer', ['>', ['get', 'value'], 60])

// 移除 filter 显示所有要素
map.setFilter('my-layer', null)
```

---

## 本课小结

- filter 在渲染前过滤要素
- `all` / `any` 组合多个条件
- `setFilter` 运行时动态修改
- filter 不影响数据源，只影响显示
