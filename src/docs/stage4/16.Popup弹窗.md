# 16. Popup 弹窗

## 概述

Popup 是 MapLibre 的信息弹窗组件。本节学习：

- Popup 创建与定位
- setHTML / setDOMContent
- 样式自定义
- 关闭事件处理

---

## 基本用法

```ts
new maplibregl.Popup({ offset: 25 })
  .setLngLat([116.39, 39.91])
  .setHTML('<b>北京</b><p>首都</p>')
  .addTo(map)
```

## 构造参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `offset` | 偏移量 | `0` |
| `closeButton` | 关闭按钮 | `true` |
| `closeOnClick` | 点击地图关闭 | `true` |
| `closeOnMove` | 地图移动关闭 | `false` |
| `maxWidth` | 最大宽度 | `'240px'` |
| `anchor` | 锚点方向 | 自动 |
| `className` | 自定义类名 | 无 |

## setDOMContent

```ts
const div = document.createElement('div')
div.innerHTML = '<h3>详情</h3><p>内容</p>'

popup.setDOMContent(div)
```

## 关闭事件

```ts
popup.on('close', () => {
  console.log('弹窗已关闭')
})
```

---

## 本课小结

- Popup 支持 HTML 和 DOM 内容
- `className` 自定义样式
- 事件处理：`open` / `close`
