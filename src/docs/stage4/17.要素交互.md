# 17. 要素交互

## 概述

MapLibre 提供了丰富的要素交互能力。本节学习：

- queryRenderedFeatures / querySourceFeatures
- 鼠标悬停高亮
- 点击弹出详情
- 要素状态（setFeatureState）

---

## queryRenderedFeatures

查询指定位置/范围内已渲染的要素：

```ts
// 查询鼠标位置的要素
map.on('click', (e) => {
  const features = map.queryRenderedFeatures(e.point, { layers: ['my-layer'] })
  if (features.length > 0) {
    console.log(features[0].properties)
  }
})
```

## setFeatureState

为要素设置临时状态，不修改数据源：

```ts
// 设置状态
map.setFeatureState({ source: 'my-source', id: featureId }, { hover: true })

// 在 paint 中使用状态
paint: {
  'fill-color': ['case', ['boolean', ['feature-state', 'hover'], false], '#ff0000', '#0000ff']
}
```

---

## 本课小结

- `queryRenderedFeatures` 查询可见要素
- `setFeatureState` 设置临时状态实现高亮
- 结合 `mouseenter` / `mouseleave` 实现悬停效果
