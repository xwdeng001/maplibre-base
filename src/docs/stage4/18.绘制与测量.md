# 18. 绘制与测量

## 概述

本节学习在地图上绘制点/线/面以及距离和面积测量。

- 使用 MapLibre 原生 API 实现绘制
- 距离测量（Haversine 公式）
- 面积计算

---

## 绘制原理

1. 监听地图 `click` 事件获取坐标
2. 将坐标添加到 GeoJSON 数据源
3. 实时更新图层渲染

```ts
const points: [number, number][] = []

map.on('click', (e) => {
  points.push([e.lngLat.lng, e.lngLat.lat])
  updateDrawLayer(points)
})
```

## 距离计算

```ts
function haversineDistance(p1: [number, number], p2: [number, number]): number {
  const R = 6371000
  const toRad = (d: number) => d * Math.PI / 180
  const dLat = toRad(p2[1] - p1[1])
  const dLng = toRad(p2[0] - p1[0])
  const a = Math.sin(dLat/2)**2 + Math.cos(toRad(p1[1])) * Math.cos(toRad(p2[1])) * Math.sin(dLng/2)**2
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a))
}
```

## 本课小结

- 绘制基于 click 事件 + GeoJSON 动态更新
- Haversine 公式计算球面距离
- 实际项目可使用 Turf.js 简化计算
