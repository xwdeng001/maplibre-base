# 15. Marker 标记点

## 概述

Marker 是基于 DOM 的地图覆盖物，独立于 WebGL 渲染管线。本节学习：

- Marker 创建与定位
- 自定义 DOM 内容
- 拖拽 Marker
- Marker 与 Popup 联动

---

## 基本用法

```ts
const marker = new maplibregl.Marker()
  .setLngLat([116.39, 39.91])
  .addTo(map)
```

## 自定义 DOM

```ts
const el = document.createElement('div')
el.innerHTML = '📍'
el.style.fontSize = '32px'

const marker = new maplibregl.Marker({ element: el })
  .setLngLat([116.39, 39.91])
  .addTo(map)
```

## 可拖拽 Marker

```ts
const marker = new maplibregl.Marker({ draggable: true, color: '#ff0000' })
  .setLngLat([116.39, 39.91])
  .addTo(map)

marker.on('dragend', () => {
  const lngLat = marker.getLngLat()
  console.log(`新位置: ${lngLat.lng}, ${lngLat.lat}`)
})
```

## Marker + Popup

```ts
const popup = new maplibregl.Popup({ offset: 25 })
  .setHTML('<b>北京</b>')

const marker = new maplibregl.Marker()
  .setLngLat([116.39, 39.91])
  .setPopup(popup)
  .addTo(map)
```

---

## 本课小结

- Marker 是 DOM 元素，不受 WebGL 样式限制
- 支持自定义 DOM、拖拽、颜色配置
- `setPopup` 将 Popup 绑定到 Marker
